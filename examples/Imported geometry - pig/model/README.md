# Origins of the Pig

The pig mesh in this directory comes from Keenan Crane's 3D Model Repository:

<https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/>

The repository identifies **Origins of the Pig** and its associated data as
dedicated to the public domain under the Creative Commons CC0 1.0 Universal
Public Domain Dedication. The original archive is available at:

<https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/pig.zip>

No texture is required by the OVF geometry example; only the triangular OBJ
surface is used.

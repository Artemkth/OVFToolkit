# OVFToolkit documentation

OVFToolkit provides lazy C++ and NumPy access to OOMMF vector-field files,
conversion utilities, and CPU/CUDA batch Fourier transforms.

## Start here

- Install and use the Python package from the
  [project README](https://github.com/Artemkth/OVFToolkit#python-package).
- Build and install the command-line tools from the
  [platform instructions](https://github.com/Artemkth/OVFToolkit#command-line-tools).
- Follow the [worked examples](examples/index.md) for complete simulation and
  analysis pipelines with saved outputs.
- Look up the [Python and C++ APIs](reference/index.md) in the reference
  section.

The example pages are rendered from their checked-in Jupyter notebooks. The
documentation build never executes notebook code or starts MuMax3.

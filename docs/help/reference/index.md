# API reference

OVFToolkit exposes the same OVF data model through a C++ library and a typed
Python package.

- The [Python API](python.md) covers lazy readers, streaming writers, vector
  fields, metadata, NumPy views, mesh coordinates, and spectrum reduction.
- The [C++ API](../generated/cpp-api/index.html) is generated directly from the
  public headers with Doxygen.

The complete simulation and analysis pipelines remain in the
[worked examples](../examples/index.md).
